# 04 — Experiência do Usuário (15%)

## Tese
A experiência deve tornar informações operacionais compreensíveis e acionáveis para gestores, operadores e visitantes, sem exigir conhecimento técnico especializado.

## Perfis de usuário
- Gestor: acompanha indicadores, ocorrências e resultados.
- Operador/responsável: analisa alertas, registra ações e atualiza status.
- Visitante: conhece a proposta e visualiza informações selecionadas por meio de QR Code.

## Jornadas a documentar
### Gestor
Acessa o dashboard → interpreta indicadores → consulta ocorrência → acompanha resolução → avalia histórico.

### Operador
Recebe/consulta alerta → verifica a situação → registra ocorrência → atualiza providências → conclui ou encaminha.

### Visitante
Escaneia QR Code → acessa página pública apropriada → entende o projeto e os indicadores autorizados.

## Critérios de UX
- Clareza de linguagem e indicadores.
- Navegação consistente.
- Acessibilidade e legibilidade.
- Responsividade em diferentes telas.
- Feedback claro de sucesso, erro e carregamento.
- Separação entre dados administrativos e informações públicas.
- Proteção de dados e controle de acesso.

## Testes com usuários
Registrar tarefas, perfil dos participantes, dificuldades, tempo de execução, feedback e melhorias realizadas. Não declarar usabilidade validada sem teste.

## Evidências a inserir
- `evidencias/`: capturas reais, protótipos, vídeos de navegação e resultados de testes.
- `metricas/`: tarefas concluídas, erros observados e feedback.
