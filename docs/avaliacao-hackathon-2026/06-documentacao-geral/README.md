# 06 — Documentação Geral

Use esta pasta para materiais que apoiam mais de um critério:
- `arquitetura/`: diagramas, tecnologias, fluxo de dados e integrações.
- `produto/`: visão geral, funcionalidades e manual de uso.
- `equipe/`: integrantes, responsabilidades e contatos institucionais autorizados.
- `referencias/`: normas, artigos, fontes de mercado e documentação técnica.

Não armazenar senhas, tokens, chaves de API, dados pessoais desnecessários ou credenciais.
