# Dados hídricos e preservação

Não limpar/resetar banco para mudar de escopo. Migração do mapa é aditiva e registros existentes são preservados. Tabelas antigas saíram das jornadas operacionais, sem exclusão de dados.

Seed mantém cadastros e não inventa leitura por padrão. Vincular cada medidor ao ponto correto exige conferência física humana. DEVICE informa origem declarada; não aprova calibração. Potenciômetro é SIMULATED. Não repetir um único sinal por cômodos para simular vários sensores.

Evidências: firmware/commit, diagrama/fotos, referência de volume, pulsos por litro, erro e correlação de hora/código/vazão com BI. Revisar cópias destinadas à banca para retirar credenciais e dados pessoais. ZIP de código não inclui banco, ambiente privado ou dependências instaladas.
